# 故障排查（Troubleshooting）

## CLI 找不到
1. 设置 → Agent CLI 工具 → 看检测状态。
2. 未安装：按页面上的官方指引安装（如 `npm install -g @anthropic-ai/claude-code`）。
3. 装好后点"重新检测"。仍检测不到：新开终端运行 `claude --version` 确认；确认安装到了 PATH 中的位置。
4. 游戏不会伪造检测结果——检测不到就是没装好。

## API 错误
| 提示 | 原因与处理 |
|---|---|
| Key 无效或没有权限 | 检查 Key 拼写、账户余额、权限范围 |
| 找不到这个模型 | 模型名与服务商完全一致（区分大小写） |
| 请求太频繁 | 等几十秒；检查额度 |
| 连不上服务商 | 检查网络/代理/Base URL |
| 返回内容无法解析 | Base URL 指向了非兼容接口 |

全部主线不配置 AI 也能玩——API 错误从不阻断游戏。

## 网络问题
- 优先级：本地网络 → 代理设置 → Base URL → 服务商状态页。
- 真实 CLI 任务依赖网络；教学模拟模式完全离线可用。

## 存档损坏
- 症状：读取时提示"存档损坏/结构损坏/版本过高"。
- 处理：存档位于 `%APPDATA%/metis-academy/metis-data/`。自动存档（槽位0）通常完好，先试读它；损坏的手动档可整行删除后重新保存。
- 版本提示"高于当前支持版本"：说明存档来自更新版应用，请升级应用。

## 终端 / Agent 任务失败
1. 确认已"选择工作目录"（终端页左上角）——未授权目录任务会被拒绝。
2. 确认退出码与日志尾部：报错最后 30 行是金子。
3. 任务被取消显示"用户取消"。
4. 长任务无输出：点"停止"后重试；真实 CLI 首次运行可能有登录引导。

## 性能
- 冷启动慢：首次启动会初始化数据目录，属正常。
- 剧情卡顿：几乎不可能——若出现请反馈（附"关于"页版本信息）。
