# METIS Academy 用户手册

> 写给玩家的说明书。不涉及任何开发概念。

## 一、你要做什么

你是一个普通学生。三条故事线，三次真实的历练：

1. **科研线（30天）**：导师一句话，30天后开题答辩。
2. **竞赛线（21天）**：从比赛通知到决赛路演。
3. **创业线（30天）**：从没有项目，到第一个愿意付钱的用户。

游戏里你会遇到的"AI Agent"，就是现实中的 Claude Code、Codex、DeepSeek Harness 的教学投影。游戏不教你原理，只教你：**什么时候用、怎么给任务、怎么验收**。

## 二、基本操作

| 想做什么 | 怎么做 |
|---|---|
| 推进对话 | 点击剧情空白处 |
| 做选择 | 点击选项文字（不会显示数值好坏——像现实一样） |
| 结束一天 | 右下角"结束这一天"按钮 |
| 查历史 | 剧情页右上角时钟图标 |
| 存档 | 剧情页保存图标，或首页"存档"（0号槽是自动存档） |
| 用工作台 | 顶部导航"工作台" |

**行动点**：每天有行动点（右上角显示），某些行为会消耗它。熬夜会降低第二天的行动点——游戏模拟得相当诚实。

## 三、工作台

- **左栏**：当前任务与你的资产。资产是你在剧情里亲手产出的东西（研究简报、文献矩阵、任务契约、假设板……），它们会一直陪着你。
- **中栏**：
  - 编辑器：查看/修改资产。右侧有评分器（如任务契约评分），保存自动记版本。
  - 终端：选择工作目录（授权）后，可运行 Agent 任务；支持搜索日志/停止/清空。
  - 运行历史：每次 Agent 运行的记录。
- **右栏**：选择工具（教学模拟或本机真实 CLI）→ 写任务 → 运行；下方是 AI 对话（需配置 AI 服务）。

## 四、AI 怎么配

不配也能玩完整游戏。想配的话：设置 → AI 服务 → 添加 → 填类型/地址/模型/Key → 保存 → 测试。
Key 是加密保存的。别把 Key 发到聊天里，游戏里的角色也会提醒你这一点。

## 五、真实 CLI Agent

设置 → Agent CLI 工具 → 看检测状态。显示"未安装"时按官方指引装好后点"重新检测"。
**游戏不会假装你装好了。** 检测不到就是没有。

## 六、新手最常见的三个问题

1. **"选项都看不出对错，怎么选？"**——这就是设计。你会从失败和延迟后果里学会判断，这比跟着"+10好感"走学得快得多。
2. **"AI 给我的文献/数据能直接用吗？"**——游戏会在第8天亲自教你为什么不能。记得查证。
3. **"行动点不够了！"**——优先做会疼的事。答辩前夜修假引用 > 做精美PPT。

## 七、玩完之后

三线通关后，回看"命运回溯"：游戏会列出影响结局的关键决定和学习点。
如果玩完之后，你面对一个复杂任务时开始自然地问自己"什么叫完成？先验证什么？怎么让 Agent 持续工作？怎么检查它有没有骗我？"——这个游戏就成功了。
